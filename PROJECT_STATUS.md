# Project 6 - Inventory & Warehouse Management System

## Project Overview

Project 6 is a simple Inventory & Warehouse Management System.

The backend manages:

- Authentication
- Users and roles
- Products
- Categories
- Warehouses
- Suppliers
- Warehouse stock
- Stock movements
- Warehouse transfers
- Purchase orders

The backend is built using:

- Python
- Flask
- PostgreSQL
- psycopg2
- JWT authentication

The project follows the principle:

> Small scope, complete implementation.

The system should not be expanded into unnecessary features such as microservices, Kafka, Redis, AI/ML, advanced analytics, payment systems, real-time tracking, etc.
